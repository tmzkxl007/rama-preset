## 2. ★나레 말투 — 사용자 확정 (2026-09-18, sb01 3차 대본)

라마의드라마 7편을 분석(벤치 문서)하고 세 가지 안을 구워 사용자가 고른 것이다.

**한 줄: 3인칭 과거 존댓말로 지금 화면의 상황을 설명하는 한 문장. 물음표로 던지지 않는다. ★나레는 20% — 대사가 본문이다 (2026-09-19 사용자 확정, sb02b).**

| | 규칙 | 보기 (sb01) |
|---|---|---|
| 문장 | 한 마디 = 한 정보, 10~20자, `\|` 로 2~3덩이 | 잘못 하나 고치는 데도 \| 허락을 세 번이나 받죠 |
| 어미 ① | **~죠 / ~었죠** — 닫는다 | 허락을 세 번이나 받죠 · 다시 뜯었죠 · 똑같이 길었죠 |
| 어미 ② | **~는데 / ~했는데** — 다음 대사로 넘긴다. **물음표 없이** | 줄자로 텐트를 재기 시작했는데 |
| 어미 ③ | **~은 / ~는** — 주어만 깔고 대사가 서술어 (첫 마디에 좋다) | 혼이 난 해병 최욱은 → [이병 최욱 …] |
| 금지 | **물음표 나레** 「~은?」「~데?」「~지만?」 — 사용자: "혼난 해병은? 허락만 세 번인데? … 이런 말투 안 썼으면 좋겠어. 그냥 상황 설명" | ✗ 혼난 해병은? ✗ 줄자를 꺼내는데? ✗ 보고는 빠지지 않는데? |
| 금지 | 「~다 / ~습니다 / ~기에」 | |
| 인물 | 이름(최욱·박철용) 또는 관계어(형·동생·해병·육군). 직함은 대사 자막에만 | |
| 판단 | 나레가 시청자 대신 한 번 판단한다 | 허락을 세 번이나 받죠 · 결국 0.3cm 때문에 |
| 다리 | 「결국」「그러더니」 같은 접속으로 마디를 연다 (붓글씨 단독 「결국!」은 안 쓴다) | 결국 0.3cm 때문에 \| 다 지은 텐트를 다시 뜯었죠 |
| 촌평 | **마지막 마디만 반말 한 줄, 6~12자, 관찰자 비꼼** | 보고만 하다 하루 다 가겠네 |
| 개수·비중 | ★**나레 3~5마디 · 40~110자 · 글자 비중 약 20%(15% 이상)** — 대사를 더 들리게. 나레는 시작 주어 한 줄 → 상황 잇기 1~2 → 촌평 | sb02b: 4마디 58자 21% · 대사 219자 |
| 속도 | "드라마" 보이스 1.3배 = 6.6~7.2자/초 (벤치 6~8) | |
| 시작 | 0초 = 가장 센 그림 + 첫 나레(주어형). 대사 훅으로 시작해도 된다 | |

`build.py` 가 나레에 `?` 가 있거나 본문 마디가 `~다` 로 끝나면 `[라마 규격 위반]` 으로 막는다.

### 2-0. ★나레 20% 로 낮춘 경위 (2026-09-19)
sb01~sb06 1차는 나레 5~6마디 80~110자(27~39%)였다. 사용자: "나레이션 목표 비중을 20%로 하고 대사를 더 들리는 방향으로" → sb02b(4마디 58자 21%, 대사 219자)를 보고 **"좋아 아주 좋아"**.
줄이는 법: ① 나레가 요약하던 대사를 그대로 D 로 살린다(육군 간부↔박철용, 박수 장면, 돌아서며 하는 말) ② 첫 마디는 주어만(「~은」) ③ 상황 잇는 마디 1~2개 ④ 촌평. 그림 설명 나레("텐트를 다시 뜯었죠")는 화면이 보여 주니 뺀다.

### 2-1. 사용자가 버린 안 (다시 꺼내지 마라)
- **라마톤 1차** (벤치 그대로): 「타 군 앞에서 \| 목소리가 작다고 \| 혼난 해병은?」「허락만 세 번인데?」「결국! \| … 뜯죠」 → "~데?가 너무 많아"
- **2차** (물음표 0): 「허락만 세 번이죠」「줄자를 꺼내 들자」「뜨거운 물 하나에도 \| 보고는 어김없이」 → 사용자가 "주어?·~데? 말투 자체를 빼고 상황 설명으로" → 3차가 확정.

### 2-2. 벤치에서 가져온 것 / 안 가져온 것
| 가져옴 | 안 가져옴 |
|---|---|
| `\|` 덩이 = 컷 하나 · 나레 최소(대사가 본문) · 판단 한 줄 · 짧은 관찰자 촌평 · 「결국」 다리 | 「~데?」「주어+?」 열기 · 붓글씨 단독 감탄 · 직함 호칭(백부장 등) · 편집자 초록 괄호 |

## 3. 소재 — 세로 쇼츠 편집본을 쓸 때

남의 채널이 드라마를 편집한 세로 쇼츠(1080×1920)가 소재로 자주 온다. **권한은 사용자가 확인한다.**

1. `prep.py` 가 세로(H>W) 소재를 받으면 **그림 칸만 잘라** `src.mp4` 를 만든다(원본 `_src/raw.mp4`). 프레임별 max 로 검은 행을 재서 가장 긴 밝은 구간이 그림 칸이다.
   그 채널 자막이 그림 **안**에 있으면 하드섭 검출이 `HARDSUB_TOP` 을 잡고, `episode.py` 에 `spec.ZOOM = 1.0` 을 적어 준다 → 폭을 다 쓰고 자막 위만 쓴다(sb01: 1080×990 → 810×814 크롭).
2. **그 채널 나레 음성**이 대사 사이에 깔려 있다. 전사(`asr_ko.json`)에서 그 낱말의 시각을 잡아
   `python scripts/mute_vocals.py <편폴더> 13.05-14.56 26.75-29.20 …` 으로 지운다 — demucs 로 목소리만 갈라 그 구간만 0 으로 내리고 배경은 그대로 둔다. `asr_ko.json` 에서도 그 낱말이 빠진다.
   ★대사와 0.03초밖에 안 비는 경계가 흔하다. 대사 낱말을 물지 않게 시각을 정확히 적고, 지운 뒤 `dlgcheck` 로 0개를 다시 확인한다.
   ★나레인지 대사인지는 **자막 글꼴**로 가른다(sb01 채널: 흰 고딕=나레, 노랑 이탤릭=대사 강조) — 색만 보면 틀린다.
3. 하드섭 위쪽만 쓰면 그림이 커진다. Vmake 로 지우는 길(포레이로 §17-47)도 있지만 유료라 **사용자 승인 뒤에만**.
4. 완성본 y1440~1500(그림 맨 아래)에 흰 글자+검은 테두리 픽셀이 남는지 재서 확인한다. 밝은 위장복은 오탐이 나니 걸리면 프레임을 직접 본다.

## 4. 아래 띠 로고

작품 공식 로고(흰 글자)를 투명 PNG 로 만들어 편 폴더에 `logo.png` 로 두고 `LOGO = ("logo.png", 240, 1650)`.
만든 로고는 `assets/logos/<작품>.png` 에 모아 둔다(다음 편에서 복사).

만드는 법 (sb01, 티빙 포스터 1920×1080에서):
```
crop 후보 영역 → 밝기: min(B,G,R)>195 · max-min<35 (흰색만) → connectedComponents 로
작은 조각 정리(본문 40px 이상 · 아래 영문 줄은 6px 이상) → 알파에 GaussianBlur(3) → RGBA 저장
```
포스터는 `https://image.tving.com/...` 의 1920 짜리처럼 큰 것을 쓴다(600px 짜리는 뭉개진다).
`OUT` 파일 이름은 **영문**으로 — 한글 이름은 로고 오버레이 ffmpeg 가 `Illegal byte sequence` 로 죽는다.

## 5. 절차 — 순서를 바꾸지 마라

```powershell
$env:PATH = "$HOME\.volcano\venv\Scripts;$env:PATH"
$P = "presets\라마"
$E = "<편폴더>"                        # 예: sb02_무언가 (영문+번호로 시작)

python "$P\prep.py"      $E <URL 또는 로컬파일> [시작초] [끝초]   # 세로면 그림 칸만 오림 · 하드섭 · 컷 후보 · episode.py 뼈대
python scripts\_asr_sm.py "$E\src.mp4" "$E\asr_ko.json" ko         # 단어 시각 전사
python scripts\mute_vocals.py $E a-b a-b …                         # (남의 나레가 있을 때만)
#   ... 국면 지도 → episode.py 채우기 (§2 말투) · logo.png 놓기 ...
python "$P\dlgcheck.py"  $E "$E\asr_ko.json" 0    # 자막 없는 말 0개
python "$P\get_fonts.py" $E
python "$P\tts.py"       $E
python "$P\align.py"     $E
python "$P\reframe.py"   $E
python "$P\build.py"     $E                        # 로고까지 얹는다. [라마 규격 위반] 칸이 안 뜨면 통과
python "$P\synccheck.py" $E
python "$P\cutsheet.py"  $E                        # cutsheet.jpg 눈검사 — 딴 장소 컷이 끼면 뺀다 (sb01 3초)
```

완성본은 `rama_work/라마/<편>.mp4` 로 모이고 `<편>_업로드.txt` 를 같이 둔다. 업로드 세트 꼴은 `examples/sb01_신병4_해병보고/*_업로드.txt`:
제목 「1행 — 2행 #작품명」 · 설명 3~4줄(대사 인용) · `* 작품:` · "더 자세한 내용은 <플랫폼>에서 감상하는 걸 추천합니다!" · 해시태그는 작품명 하나.
