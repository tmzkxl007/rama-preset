## 후보 10개 (순위)

### ① 취사병 스카우트 먹방 (620~884 → 60초)  ★1순위
- 취사병이 문빛나리를 찾아와 "취사병 하자" → "저는 확실한 전투병과 재질입니다 / 전투병과는 개뿔"
- 건빵 → "**밀리터리 프렌치 토스트**" → "**까르보나라 쌀국수**" → "**필살기** … 꼬리곰탕" · "고기가 가득! 이게 바로 취사병의 특권이야"
- "전우들을 배신할 수 없습니다 / **이렇게 잘 먹어놓고**" / "모포 빨고 와서 당 떨어져서 먹은 겁니다" → 결국 "매일 음식 먹는 거 꼭 약속해 주셔야 됩니다"
- 제목안: 「음식 네 접시에 넘어간 / 전투병 지망생」 · 촌평 "전우애보다 꼬리곰탕이 진했네"

### ② 자판기 아줌마 전설 (1043~1290 → 60초)  ★2순위
- "위병소를 프리패스로 통과하는 민간인 2인방" → "우리 부대 창설 때부터 계셨던 분" / "모든 간부들의 마음을 훔쳐간 전설적인 팜 파탈"
- 회상: 행보관이 "이번 달 월급 싹 다 **100원짜리**로 바꿔왔어" → 붉은 장미 고백 → "다음 주에 우리 고향집에 같이 인사 갈래요?"
- "커피 뽑을 때 **첫 번째 칸은 뽑지 마라**, 그거 왜 그런지 알아?" → "내 사랑은 자판기 같은 기라"
- 회상 구간은 분홍 톤 화면 — 밝기·색 확인. 제목안: 「행보관 인수인계 사항에 적힌 / 자판기 첫 번째 칸」

### ③ 자판기 아줌마 실물 등장 (1290~1450 → 55초)
- 맹물만 나오는 자판기에 싸움 → "뭐 하는데" → "**이분이 그…**" / "아줌마 안녕하세요… 이모님… **누나** 안녕하세요"
- 트럭 아저씨 등장, 아줌마가 "오빠야"(행보관 아님 — sb54 확인) → "나 늘 먹던 걸로 한 잔" → "니가 나한테 사랑은 자판기라고" → 병사들 "**화생방보다 더 독한 것 같습니다**"
- ②와 이어 두 편 연작 추천. 제목안: 「전설로만 듣던 / 자판기 아줌마 등장」

### ④ 꼬리곰탕 한 입만 (884~946 → 40초)
- 비밀 약속이 먼저 퍼짐 "문빛나리 취사병 한답니다" → "이거 저희끼리만 얘기한 건데" → "**음식에 눈이 팔려가지고**"
- "**갈 땐 가더라도 꼬리곰탕 한 입만 먹고 가면 안 되겠습니까?**" → "은혜를 배신으로 갚아"
- ①의 꼬리. 40초가 안 되면 ①의 마지막 부분을 앞에 붙인다. 욕설 뺀다.
- 제목안: 「취사병 되기로 한 날 / 먼저 퍼진 소문」

### ⑤ 모포 밟기 (402~590 → 55초)
- "다들 **밟을 얼굴 한 명씩 생각했지**" → "누구 생각하면서 밟습니까" → 새까만 물 "**색깔이 완전 진간장이네**" / "박민석 너 안 씻어서 그런 거 아니야?"
- "**물 18번 갈았습니다**" / "발가락 쪼그라들었어 / **다리를 절이는 거 아닙니까**" / "20키로 행군 한 것 같습니다" → "빨래 끝!"
- 제목안: 「밟을 사람 생각하며 / 모포 빠는 군대」

### ⑥ 진간장 모포 썰 (300~392 → 45초)
- 모포 세탁법 "고무 대야에 던져놓고 … **밟고 싶었던 놈 생각하면서 밟으면 끝**"
- "나도 이등병 때 딱 한 번 빨아봤는데 … 모포가 빨아도 빨아도 계속 **진간장**이 나와" / "그때부터 **간장게장을 안 먹어**"
- "형은 간다 / 같이 빠져야지 말입니다" → 호출받고 빠짐. 욕설(존나·이지랄) 많음 — 블록에서 뺀다.
- 제목안: 「병장이 간장게장을 / 안 먹는 이유」

### ⑦ 율무차 소문 (951~1043 → 45초)
- 동전 없는 박민석 → 자판기 앞 "**율무차 남자한테 안 좋다는 소문**" → 한 명씩 커피로 바꿈 "그럼 나도 커피"
- "마음을 곱게 써야지 샘통이다 이런 표정" → 자판기 고장 "고장나면 사단장 아들이고 뭐고"
- 제목안: 「율무차 소문 하나에 / 전원 커피로 바꾼 병사들」

### ⑧ 오석진 셀프 진급 (58~160 → 50초)
- 회식 소식 → 상상 "**이제 대한민국의 안보는 오석진 대위가 책임지는 겁니다**" / "목숨을 바치겠습니다" / "그만 그만"
- 다음 장면 혼자 대위 계급장 "**또 혼자서 상상했네**" / "중대장님 진급하셔서 소대장님도 진급하신 겁니까"
- 0~57 행보관 "군납소주 한 박스" 를 앞에 붙여도 된다. 제목안: 「중대장 진급 소식에 / 혼자 진급한 소대장」

### ⑨ 전역 대신 중대에 남고 싶은 병사들 (220~300 → 50초)
- 테니스병 "주말에도 중대 업무 하겠습니다, **안 보내시면 안 됩니까**" / "외박도 외출도 못 나간다던데" / "좀 닥쳐라"(뺀다)

- ①④의 앞 이야기. 제목안: 「테니스병도 취사병도 / 안 가겠다는 병사들」
